# Plaude

*Walking slowly, on purpose.*

Plaude is a deliberately small app that passes the [Claude Code](https://claude.com/claude-code) CLI through a WebSocket into a window — a desktop app or a plain browser tab. Faster, better tools exist. That's not the point: this repo is a learning journey, adding one piece at a time so each piece of a real end-to-end app can be seen and understood.

A full guide to what each piece is and how it works is on its way.

> Plaude is a personal learning project and is not affiliated with or endorsed by Anthropic.
